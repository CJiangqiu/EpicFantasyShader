# Epic Fantasy Shader

**A fantasy shader pack focused on vibrant colors.**

Epic Fantasy Shader is a shader pack for Minecraft Java Edition, developed specifically for the *Epic Journey* series. Its visual design draws inspiration from *The Elder Scrolls V: Skyrim*, with atmosphere that adapts to the environment and vivid starry skies.

You are welcome to use it in any modpack or video, and to modify and redistribute it under the terms of the [MIT License](LICENSE.txt).
